## Observations (not failures of this batch's claims)

- **The omnibox Enter chose Create for a near-miss query.** Inside full screen, ⌘K
  "Retitled renamed" (the existing title is "Retitled, renamed") followed by ↵
  created a new document `doc_q4nzxbvg` "Retitled renamed" and opened it in the
  excursion. It did not open the existing one. §10's rule is "no exact title match → Create", so this
  may be as specified. The create row did ride the full-screen seam, as UI-200's ruling says.
- **Commit relabelling is lazy.** A window's commit keeps its `doc edit:` subject
  past the 30 s idle mark. It becomes `editing session: N documents` only when the
  next window writes. This does not affect any claim here. It is noted because a
  reader who inspects `git log` right after an idle window sees the pre-relabel subject.
- **The archive by `PUT` names its commit `doc edit: <title>`, not `doc archive:`.** The
  SERVER-106 issue records this under Escalation as a deliberate, open spec
  question. The shipped §4 rider ("the commit says what happened") is met under the
  issue's reading and not under a grep for `doc archive:`.
