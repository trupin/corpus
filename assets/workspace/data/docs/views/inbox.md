composer's Capture action, and the ＋ button on any column that is not scoped to a folder —
so you can write the thought down without deciding where it belongs. The agent files inbox
arrivals for you: it retitles them, expands them into something usable, tags them, and moves
them into a real folder. This column should tend toward empty.
